# Pippin — design notes

## Core loop
goal / check-in → **energy** → full bar → **adventure** (6–8 h, real time) → story + discovery + **acorns**
→ adventures count → **growth** (Seedling → Sprout → Sapling → Bloom → Elder). All numbers: `src/game.js`.

- Energy resets each local day. While the sprig is away, each goal brings it home 10 min sooner.
- Energy is only ever given once per goal per day (un-ticking keeps the record, so no farming).
- Streak day = at least your chosen *daily aim* of actions (gentle 1 · steady 2 · keen 3 · blazing 4).
  Pause any time. A gap of ≤3 days can be mended — first mend each month free, then 15 acorns.
- Very low mood at check-in shows real-world support (Samaritans etc.) alongside the normal flow.

## Coach (pluggable brain)
`src/brains/index.js` picks one adapter: `{ chat(history), planDay(ctx), story(ctx) }`.
- **hermes**: two agent runs — *gather* (read-only tool lookups, plain report, failures reported
  as LOOKUP FAILED) then *plan* (JSON, may only use items from the report). Single-shot "reply in
  JSON" made the agent skip its tools and invent emails, so don't merge the steps.
  `HERMES_CONTEXT_HINT` carries install-specific commands (e.g. which skill reads Gmail).
- **openai**: in-app context only.
- Plans run in the background (Hermes ≈ 1–3 min); the UI polls `GET /api/coach/plan`.

## Roadmap
**Phase 1 — done:** PIN auth, hatch/onboarding, SVG sprig with 5 stages, goals (days, tiny steps,
categories, idea library), morning/evening check-ins with emotions, energy + adventures + stories,
acorns, optional streaks (aim, pause, mend), coach day-plan + chat, adventure journal, PWA shell.

**Phase 2 — done 2026-09-28:** shop (outfits, colours, furniture) and a decoratable home; breathing
exercises; soundscapes (Web Audio, generated — no licensed audio); focus timer; stretches;
reflections/journal prompts; quizzes (public-domain PHQ-9 / GAD-7 with clear "not a diagnosis"
framing); insights (mood trends, what lifts/lowers mood); Web Push nudges; category milestones → acorns.

**Phase 3 — done 2026-09-28** (same-server friends; cross-server federation is future work): friends (by invite code, across instances), sending
encouragement, visiting homes, shared goals; tiny companion pets; seasonal events; multi-user instances.

## Not copied
The Finch app's (Finch Care PBC) name, bird character, art, branded terms (currency, social features, streak level names),
prompt/quiz/story text and layouts are not used. Mechanics are generic; every word and drawing here is original.

## Phase 2/3 notes
- Rewards hang off the core loop in `src/rewards.js`: event tokens, weekly category milestones (3/5/7 days → 5/10/20 acorns),
  journeys (one task/day issued lazily on /state; finishing → 20 acorns + snail), tool sessions (+2 energy, first 3/day),
  companions (earned only). Catalogue: `src/catalog.js`; content (original + PHQ-9/GAD-7/WHO-5): `src/content.js`.
- Art: outfits in `public/js/sprig.js` (WEAR), furniture/room in `public/js/room.js`, sounds generated by Web Audio in `public/js/sounds.js`.
- Nudges: `src/push.js` — VAPID keys generated once into `app_secrets`; a 60 s tick sends morning/evening/"home" nudges,
  each deduped in `push_sent`. Push needs HTTPS (behind the proxy) and on iPhone the app added to the Home Screen.
- People: owner adds household accounts (Me → Household); PIN login asks "who's this?" when >1 person.
  Friends see sprig + home + shared goals only — never check-ins, reflections, chat, private goals or plans.
