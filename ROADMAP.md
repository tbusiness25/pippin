# Roadmap

No dates — this is a spare-time project. Ordered by what matters most.

## Before 1.0
- [ ] Fix the security items in [docs/KNOWN_ISSUES.md](docs/KNOWN_ISSUES.md) (session revocation, CSP, DNS pinning)
- [ ] Automated tests for the API and the crisis screen
- [ ] Accessibility pass (screen readers, contrast, reduced motion)
- [ ] One-command install script and a demo instance with fake data
- [ ] Country packs for helplines (crisis, alcohol, drugs, gambling) beyond the UK

## Next
- [ ] Watch screen for other wearables SparkyFitness already syncs (Fitbit, Oura, Polar, Withings…)
- [ ] Goals that tick themselves from your watch ("7 hours' sleep", "6,000 steps") without needing an agent
- [ ] Barcode scanning for food
- [ ] Translations
- [ ] Calendar (CalDAV/ICS) read-only for the morning plan without needing an agent
- [ ] Better offline conflict handling
- [ ] Coach evaluation harness: compare models on the red-team suite and publish results
- [ ] Optional end-to-end encrypted backup

## Maybe
- [ ] Android app via Trusted Web Activity (the PWA already installs on Android)
- [ ] A shared "body doubling" room for friends on the same server

## Won't do
- Ads, tracking or selling data
- Paywalled self-care tools
- Shame mechanics: decaying pets, lost progress, streak resets as punishment
- Sending your mental-health data to a cloud model by default
