# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, and remember many people here have ADHD — missed replies, long gaps and
typos are normal and never a reason for snark. No harassment, no discrimination, no sharing anyone's personal
or health information.

People talking about addiction, mental health or relapse here deserve particular care. Don't moralise.

Report problems by email to the maintainer (see the GitHub profile). Reports are kept confidential.

**This repository is not a support service.** If you're struggling right now: in the UK call Samaritans on
116 123 or text SHOUT to 85258; in an emergency call 999. Elsewhere, see [findahelpline.com](https://findahelpline.com).
